# Scenes

Each folder here is one scene, written by someone else and kept under its author's own licence. The MIT licence at the top of this repository covers the app's code; it does not cover these folders.

- A scene's `LICENSE` file holds its licence text, its credit, where the licence is stated, and what was changed in porting it.
- [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md) lists them all.
- [NONCOMMERCIAL.md](NONCOMMERCIAL.md) lists the ones that may not be used commercially.
- [docs/SHADERS.md](../docs/SHADERS.md) describes the format and how to add one.
